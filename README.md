# sistem-panen-nadhifa-aprilia
Program Python sederhana untuk menghitung total nilai hasil panen dan perhitungan diskon.

## Deskripsi
Sistem Panen merupakan program Python sederhana yang digunakan untuk menghitung total nilai hasil panen berdasarkan jumlah hasil panen dan harga per kilogram. Program ini juga dilengkapi dengan fitur perhitungan diskon.

## Cara Menjalankan Program
1. Pastikan Python sudah terinstal pada komputer.
2. Buka folder proyek `sistem-panen` melalui Visual Studio Code.
3. Buka terminal pada folder proyek.
4. Jalankan perintah:
```bash
python Panen.py
```
5. Program akan menampilkan komoditas, jumlah panen, total nilai panen, diskon, dan total nilai panen setelah diskon.
